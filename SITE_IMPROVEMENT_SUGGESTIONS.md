# Buna Coffee Leaf Library - Whole-Site Improvement Suggestions

This note is advisory only. It does not change Doors One to Eight.

## Purpose

Keep the original Buna library, but make it easier to read, easier to navigate, and more consistent across phones and larger screens.

## 1. One shared page frame

Use one shared set of rules for:

- page width
- body type
- heading sizes
- section spacing
- source lines
- note boxes
- caution boxes
- previous and next links
- footer treatment

Do not force every page to look identical. Traditions, research papers, sensory lessons and tools can keep their own character inside the same frame.

## 2. Mobile first

Check every page at narrow phone width before desktop review.

- navigation must scroll horizontally rather than wrap over content
- sticky bars must not cover headings
- tables must scroll or collapse safely
- long source links must wrap
- cards must become one column
- buttons and links must have comfortable touch targets

## 3. A simple source protocol

For research-dependent statements:

1. say what kind of source it is
2. explain the finding in plain language
3. link the source close to the claim
4. state an important limit when needed
5. repeat the full citation in a Sources section

Keep these source types separate:

- human intervention
- human observational
- animal
- cell model
- laboratory assay
- review
- traditional report
- regulatory source
- Buna field observation
- Buna hypothesis

## 4. Reduce repeated information

Before adding a new explanation, check whether the subject is already well covered elsewhere.

If it is, give the reader a short bridge and link to the stronger existing page.

Examples:

- chemistry should link to the Reactive Landscape and sensory chemistry
- processing should link to the Process Compass and processing papers
- Chemo and Engere cultural detail should remain in their tradition pages
- Door Nine should explain the biological question, not repeat the cultural or chemical chapters

## 5. Homepage and catalogue

The homepage should remain simple. Each Door card should answer three questions:

- What is this section about?
- Who is it useful for?
- Where should I start?

The catalogue should list all Doors consistently and should eventually include Door Nine under a clear Human Biology heading.

## 6. Navigation

Keep one shared top navigation across the library.

Recommended order:

Buna Library, D1 Begin, D2 Traditions, D3 Processing, D4 Chemistry, D5 Tools, D6 Sensory, D7 Culinary, D8 Vocabulary, D9 Biology, Catalogue

Within long sections, use a second small horizontal section navigation only when it genuinely helps.

## 7. Existing health material

Do not maintain a separate health-benefits chapter that competes with Door Nine.

The old URL should remain available, but it should guide readers to Door Nine. This preserves old links while keeping one evidence standard.

## 8. Language

Prefer ordinary language.

- explain technical words when first used
- avoid promotional health wording
- avoid jargon where a simple phrase works
- avoid dramatic claims
- avoid decorative symbols that do not help navigation
- keep uncertainty visible

The library should feel like a patient guide, not a sales page or an academic paper pretending to be simple.

## 9. Verification before publication

For every revised page:

- open every internal link
- open every external source link
- confirm title, author, year and evidence type
- check that the text does not claim more than the source
- check phone layout
- check sticky navigation
- check previous and next links
- check that no old page contradicts the revised evidence statement

## 10. Work order

Suggested order after Door Nine is accepted:

1. shared navigation
2. homepage and catalogue
3. reference and chemistry pages
4. tradition landing pages
5. sensory pages
6. processing pages
7. vocabulary
8. tools and interactive pages
9. final link and mobile audit

Make these changes gradually. The aim is to make the original library coherent, not to rebuild it.
