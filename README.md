# Coffee-Leaf-Files

Buna Coffee Leaf Library — an open repository documenting traditional and modern coffee-leaf beverage pathways, including Engere, Kuti, Chemo, Kawa Daun, Citane experimental pathways, sensory work, vocabulary, culinary material, and human-biology research notes.

## Authoritative production architecture

The production path is:

**GitHub (`koffykraft/Coffee-Leaf-Files`) → Cloudflare Pages → `https://buna.koffykraft.coffee`**

Cloudflare Pages Functions under `functions/` are the only serverless runtime used by the site. Current AI/helper routes are exposed through neutral `/api/...` paths such as `/api/companion` and `/api/epsilon`.

Netlify is not part of the production architecture and no Netlify function tree is required for the current site.

## Repository material

The repository includes HTML references, brewing and processing protocols, sensory notes, experimental records, research-linked observations, interactive tools, vocabulary material, and supporting assets.

## Current reconstruction program

The existing site is being audited as source material for a bottom-up rebuild. Each published page is being assessed separately for:

1. content;
2. context;
3. truth, validity and meaning alignment;
4. information architecture;
5. visual representation;
6. navigation and indexing;
7. bibliography, citations and references;
8. cross-library duplication and contradiction.

The rebuild architecture will be derived from the completed page dossiers and whole-library synthesis rather than by preserving accidental legacy structure.
