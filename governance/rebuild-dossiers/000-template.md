# Buna Page Reconstruction Dossier

Page:
Canonical role:
Audit state: NOT STARTED

## 1. Intended reader outcome

What should the reader understand, be able to do, or know how to investigate after this page?

## 2. Content map

Record each section in order and its actual function.

## 3. Sentence / claim audit

For every substantive statement record where needed:

| Location | Statement / proposition | Type | Evidence/source | Meaning risk | Disposition |
|---|---|---|---|---|---|

Types: FACT / STUDY RESULT / OBSERVATION / TRADITIONAL REPORT / INTERPRETATION / HYPOTHESIS / RECOMMENDATION / RHETORICAL FRAME.

## 4. Context audit

Prerequisites, missing context, duplicated context, material belonging elsewhere, and expected next page.

## 5. Message-engine audit

Assess truth, evidence level, certainty, semantic precision, reader takeaway, contradiction, overclaiming, underclaiming and inference leakage.

## 6. Page architecture

Keep/reorder/move/split/merge decisions for sections and information units.

## 7. Visual and interaction audit

Mobile and desktop layout, hierarchy, density, navigation collisions, tables, callouts and visual semantics.

## 8. Navigation and indexing audit

Global navigation, Door navigation, breadcrumb, local section index, previous/next, context links and duplicate controls.

## 9. Bibliography and citation audit

Every citation/reference relationship, source quality, link integrity, unused references and unsupported claims.

## 10. Cross-library comparison

Duplicate explanations, competing pages, terminology conflicts, obsolete versions and opportunities to consolidate.

## 11. Rebuild disposition

For each major unit: KEEP / KEEP WITH EDIT / REWRITE / MOVE / MERGE / SPLIT / REFERENCE ONLY / ARCHIVE / REDIRECT / RETIRE.

## 12. Proposed rebuilt page

Purpose, outline, required evidence boxes, context links, references and page archetype.

## Acceptance

This dossier is COMPLETE only when every substantive sentence and citation has been reviewed and the page has a rebuild disposition. Structural inspection alone is not completion.
